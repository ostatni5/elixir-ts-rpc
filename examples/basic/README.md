# examples/basic

A minimal end-to-end demo: a React SPA hitting an Elixir Plug backend with cookie
session auth, and TypeScript types generated from Elixir `@spec`s.

## Quick start

```bash
cd examples/basic
./run.sh
# open http://localhost:5173
```

Credentials: `alice / wonderland` (admin) or `bob / builder` (user).

## Manual start (without run.sh)

From `examples/basic`:

```bash
# 1. Build and generate the client
(cd server && mix deps.get && mix compile)
npm install --prefix ../..
npm run rpc:gen --workspace=@examples/basic-client

# 2. Start the Elixir server on :4001 (leave running)
(cd server && mix run --no-halt)

# 3. In a second terminal, start Vite → http://localhost:5173
npm run dev --workspace=@examples/basic-client
```

## Architecture

Requests go same-origin through the Vite dev server, which proxies `/auth/*` and
`/rpc/*` to the Elixir Plug backend on `localhost:4001`. Because the browser only
sees `localhost:5173` and the session cookie is `SameSite=Lax`, no CORS is needed.

```text
Elixir Plug pipeline (BasicServer.Endpoint):
  Plug.Logger
  → Plug.Session (cookie store, SameSite=Lax)
  → :fetch_session
  → BasicServer.AuthPlug       ← POST /auth/login + /auth/logout
  → RpcElixir.Plug             ← handles /rpc/* (BasicServer.Router)
       auth.me, users.list/get/update/delete   (middleware: RequireUser)
```

Login and logout are plain Plug routes in `BasicServer.AuthPlug`, not RPC
procedures, because they mutate the session cookie and RPC handlers cannot write
to the response. `auth.me` stays RPC because it only *reads* the session. See
[how it works](https://ostatni5.github.io/elixir-ts-rpc/guide/how-it-works).

## Regenerating TypeScript types

```bash
npm run rpc:gen --workspace=@examples/basic-client
# or directly:
cd server && mix rpc.gen.ts --router BasicServer.Router --out ../client/src/rpc.gen.ts
```

To regenerate on every Elixir source change (recompiles first, so `@spec` edits
are picked up), run the watch task — it needs the `:file_system` dev dependency
already declared in the server's `mix.exs`:

```bash
npm run rpc:gen:watch --workspace=@examples/basic-client
```

## Project structure

```
examples/basic/
  run.sh                   boot backend + Vite dev server
  server/                  Elixir Plug server (Mix project)
    lib/basic_server/
      application.ex       starts Cowboy on :4001
      endpoint.ex          Plug pipeline
      auth_plug.ex         POST /auth/login + /auth/logout (session writes)
      root_plug.ex         injects secret_key_base
      router.ex            RpcElixir.Router (auth.me, users.list/get/update/delete)
      users.ex             in-memory user store
      handlers/            use RpcElixir.Handler (captures @spec for the router)
      middleware/require_user.ex
  client/                  Vite + React SPA
    src/rpc.gen.ts         GENERATED by run.sh (gitignored)
    src/rpc.ts             creates the typed client
    src/App.tsx            login form, user list, logout
```

## What this demo proves

- `RpcElixir.Plug` handles HTTP transport with cookie-session integration.
- `@spec` types flow from Elixir to TypeScript via codegen — no hand-written types.
- Typed errors round-trip: `users.update` returns a typed error union the SPA
  discriminates with per-procedure guards (see `App.tsx`).
- The Vite proxy makes same-site cookies work without CORS.
- Full cookie-auth round-trip: login → session → protected procedure → logout.
